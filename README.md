# Data-Job-Market-Analysis-Dashboard
An interactive Power BI dashboard analyzing trends in the data job market, including job roles, salary insights, and demand visualization. Built using Power BI and DAX with interactive charts, KPI cards, slicers, and drill-through reports to showcase data analysis and business intelligence skills.

# Features :
- Interactive Power BI Dashboard
- Salary & Job Trend Analysis
- Multiple Data Visualizations
- Slicers & Drill-through Reports
- KPI Cards & Tables

# Tools Used
- Power BI
- DAX
- Data Visualization
- Data Cleaning & Transformation
